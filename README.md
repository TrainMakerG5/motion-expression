# Expression — AviUtl2向けJavaScriptエクスプレッション

JavaScriptの式で、座標やエフェクトの強さ、文字列、色などを時間に合わせて変化させるプラグイン・スクリプトです。
Windows 64ビット版のAviUtl2 2.1.15以降で使用できます。

## できること

| やりたいこと | 使用する機能 | 式の入力場所 |
| --- | --- | --- |
| X座標やぼかしの範囲など、数値項目を式で動かす | JSエクスプレッション | 専用の式編集パネル |
| 座標・回転をまとめて動かしたり、色・チェック項目を指定してエフェクトを実行する | JS制御 | JS制御の設定にある「JavaScript」欄 |
| 表示する文字列・文字色・表示状態を変える | JSテキスト | JSテキストの設定にある「JavaScript」欄 |

## インストール

1. [Releases](https://github.com/TrainMakerG5/motion-expression/releases) から配布ZIPをダウンロードし、展開します。
2. AviUtl2を終了し、以下のフォルダをコピーします。`licenses` フォルダも含めて配置してください。
3. AviUtl2を起動し、追加したプラグイン・スクリプトの信頼確認を行います。

| ZIP内のフォルダ | AviUtl2の `data` フォルダを使用する場合のコピー先 |
| --- | --- |
| `Plugin/Expression` | `data/Plugin/Expression` |
| `Script/Expression` | `data/Script/Expression` |

`data` フォルダを使用していない場合は、AviUtl2のデータ保存先である `ProgramData/aviutl2` 内の `Plugin`・`Script` に配置します。
更新する場合も、AviUtl2を終了してからフォルダごと上書きしてください。

展開したフォルダの `README.md`・`LICENSE` は保持してください。これらをAviUtl2のデータ保存先へコピーする必要はありません。
AviUtl2本体は同梱していません。

## 数値項目に式を設定する（JSエクスプレッション）

### 基本的な使い方

1. 本体のウィンドウ一覧から「JSエクスプレッション」を表示します。
2. タイムラインでオブジェクトを選び、パネル上部の一覧から数値項目を選びます。
3. 式を入力し、「計算を確認」で現在時刻の計算結果を確認します。
4. 「適用」で対象のパラメーターに式を結び付けます。パネルは開いたまま引き続き操作できます。

パネルはタイムラインなどと同じ本体のウィンドウとして登録され、本体の配置機能で好きな位置にドッキングして使えます。
設定画面の数値項目を右クリックして「JSエクスプレッションを編集」を選ぶことでも、その項目を直接パネルに表示できます。
式が設定されている項目は、一覧の先頭に `[JS]` 付きで表示されます。

付属の `examples/Expression-demo.aup2` を開くと、設定済みの式を試せます。
X座標に `value + time * 60`、ぼかしの範囲に `value + time * 30` が設定されており、オブジェクトを選ぶとパネルの一覧から登録済みの式を確認・編集できます。

### 式の書き方

```js
value + Math.sin(time * 2) * 100
```

- `value`: 式を適用する前の元の数値
- `time`: オブジェクト開始からの経過秒数
- `frame`: オブジェクト基準のフレーム番号

これらはすべて読み取り専用です。最後に評価された式の数値がそのまま計算結果になります。

```js
const amplitude = 100;
const frequency = 2;
value + Math.sin(time * frequency) * amplitude;
```

- トップレベルでの `return` は使用しません。評価結果は有限の数値である必要があります。
- 「式を有効にする」のチェックを外して適用すると、式を保持したまま元の値（固定値・直線移動）を使用します。
- 「元の設定に戻す」を押すと式の結び付けを解除し、編集済みの基準値を保ったまま元の移動方法へ戻します。

### プレビューと保存

コード入力欄の上には、編集カーソルの位置に合わせた「元の値」「現在値」が表示されます。
編集中は「未適用の式」の計算結果も表示されるので、適用前に値を比較できます。
対象オブジェクトの範囲外や、式にエラーがある場合は、その理由を表示します。
計算結果は、適用先の数値範囲や精度に合わせて丸められる場合があります。

編集中のコードは、別の項目やオブジェクトを選んでも保持されます。
「適用」または「変更を破棄」を選んでから、次の項目へ移動してください。
**プロジェクトを保存する前に「適用」で式を確定してください。未適用のコードは保存されません。**

### 対応する項目と保存

- 適用した式はプロジェクト（`.aup2`）に保存されます。
- 同じ式が付いたオブジェクトを複製しても、片方の式の編集がもう片方に影響することはありません。
- 式の編集はUndo（元に戻す）に対応しています。
- 「固定値」および「加減速・時間制御・参照式を使わない直線移動」に対応しています。それ以外の移動方法が設定されている項目には適用せず、パネル上に理由を表示します。
- パネルからの式の適用は数値トラックバーが対象です。色・文字列・チェック項目の動的な制御には、後述の「JS制御」「JSテキスト」を使用します。Adobe After EffectsソフトウェアのエクスプレッションAPI互換には対応していません。

## 動きやエフェクトをまとめて制御する（JS制御）

1. 図形やテキストをタイムラインに配置します。
2. アニメーション効果から、Expressionの「JS制御」を追加します。
3. 初期コードではオブジェクトが左右に揺れます（トラックバーAが振幅、Bが速さ）。
4. 「JavaScript」のテキスト欄を編集して動作を変更します。

### 書き方

```js
const amplitude = controls.a;
const speed = controls.b;

obj.x += Math.sin(time * speed) * amplitude;
obj.rotation += time * controls.c;
```

| 名前 | 意味 |
| --- | --- |
| `time` | オブジェクト開始からの経過秒数 |
| `frame` | オブジェクト基準の現在フレーム番号 |
| `controls.a`, `.b`, `.c` | エフェクト内のA・B・Cトラックバーの値 |
| `obj.x`, `.y`, `.z` | 相対座標 |
| `obj.rotationX`, `.rotationY`, `.rotation` | X・Y・Z軸回転（単位：度） |
| `obj.scaleX`, `.scaleY`, `.scaleZ` | 各軸の拡大率（`1` が等倍） |
| `obj.opacity` | 不透明度（`0` 〜 `1`） |
| `obj.visible` | 表示するかどうか（`true` / `false`、初期値は `true`） |

### A・B・Cスライダーの使い方

A・B・Cは、式の中で自由に役割を決められる調整用スライダーです。
`controls.a`・`controls.b`・`controls.c` でそれぞれの値を参照します。
上の例ではAが揺れ幅、Bが揺れる速さ、Cが1秒あたりの回転角度になります。
初期コードではAとBを使用し、Cは使用しません。
式を書き換えずにスライダーで動きを調整でき、スライダー自体にも移動を設定できます。

### 計算結果の反映

`obj` の各プロパティは、このアニメーション効果に入った時点の値で初期化されます。
計算結果は描画時の値にのみ反映され、「標準描画」などの設定欄自体を書き換えるものではありません。
入力した式は、プロジェクト内のエフェクトのテキスト設定として保存されます。

構文としては `const`、`let`、関数、配列、条件分岐、`Math` などが使用できます（ブラウザーやNode.js固有のAPIは提供していません）。
`return` の戻り値は使われず、`obj` の各プロパティへ代入した値が最終的な描画に反映されます。

### 色・チェック項目を含むエフェクトの実行

`obj.effect(エフェクト名, 設定項目)` で、描画中の画像にエフェクトを実行できます。
設定項目はオブジェクトで渡し、値には有限の数値・文字列・真偽値を指定できます。チェック項目には `true` / `false` を使います。

```js
obj.effect("単色化", {
    "色": Math.floor(time) % 2 === 0 ? "ff8800" : "0088ff",
    "輝度を保持する": false
});

if (time < 2) {
    obj.effect("ぼかし", {"範囲": 10 + time * 20});
}
obj.visible = Math.floor(time * 2) % 2 === 0;
```

トラックバーとチェック項目以外は、AviUtl2のエイリアスファイルに保存される項目名と値の書式を使用します。
例えば、単色化の「色」は `"ff8800"` のように6桁の16進文字列で指定します。
文字列を受け取るエフェクトには文字列をそのまま渡せます。利用できる項目と値は、実行するエフェクトの仕様に従います。

エフェクトはコードに書いた順序で実行します。条件分岐で呼び出しを省けば、そのフレームでは実行されません。
既存のエフェクトの設定欄や有効状態を変更する機能ではなく、JSから指定した設定でエフェクトを追加実行する仕組みです。
この機能はメディアオブジェクトで使用します。

JSの実行と出力値の検証がすべて成功してから、描画への反映を開始します。
本体側でエフェクトの実行に失敗した場合、それ以前に実行済みのエフェクトを取り消す機能はありません。
1回のJS実行につきエフェクトは64件まで、1件の設定項目は64件まで、設定値などの合計は256 KiBまでです。

## 文字列や文字色を変える（JSテキスト）

メディアオブジェクトとしてExpressionの「JSテキスト」を追加すると、文字列・文字色・表示状態をJSで変更できます。
「元の文字列」「文字色」「表示する」で元の値を設定し、「JavaScript」にコードを入力します。
フォントと文字サイズも設定できます。初期コードではAトラックバーの値から秒数を引いたカウントダウンを表示します。

```js
obj.text = "残り " + Math.max(0, Math.ceil(controls.a - time)) + " 秒";
obj.color = Math.floor(time) % 2 === 0 ? 0xffffff : 0xff8800;
obj.visible = time < controls.a;
```

| 名前 | 意味 |
| --- | --- |
| `obj.text` | 表示する文字列。「元の文字列」で初期化されます。改行は `\n` で指定します。 |
| `obj.color` | 文字色。「文字色」で初期化されます。`0x000000` 〜 `0xffffff` の整数で指定します。 |
| `obj.visible` | 表示するかどうか。「表示する」で初期化される真偽値です。 |

`time`・`frame`・`controls.a` / `.b` / `.c` と、座標・回転・拡大率・不透明度も「JS制御」と同様に使えます。
`obj.effect()` で、生成した文字画像へエフェクトを実行することもできます。
`obj.text` と `obj.color` を描画へ反映するのは「JSテキスト」です。既存の「テキスト」オブジェクトの入力欄へ式を結び付ける機能はありません。

`examples/Expression-extended-demo.aup2` では、4秒の位置から文字列・文字色・表示状態の変更、8秒の位置からエフェクトの色変更と表示状態の変更を試せます。

## 共通の制限事項

- 評価のたびに独立したJS実行環境を生成するため、前フレームの変数やグローバル変数は保持されません。
- 別時刻のキーフレーム参照、別オブジェクトの参照、After EffectsのAPI互換はありません。
- コード長は最大64 KiB、JSのメモリ上限は16 MiB、1回あたりの実行時間は約50 msで打ち切られます。
- 文字列およびエフェクトの項目名・設定値はそれぞれUTF-8で64 KiBまでです。NUL文字は使用できません。
- JS制御とJSテキストでは、不透明度は `0` 〜 `1` の範囲で指定します。
- パラメーターごとの数値の範囲や精度は、対象トラックバー側の制限にも従います。
- 適用前の計算確認に加え、再生中に式の評価が失敗した場合はLuaエラーとして通知されます。エラー発生時に特定フレームの値へフォールバックする機能はありません。
- エラーメッセージには `expression.js` の位置情報が含まれる場合があります。JS制御とJSテキストでは、行番号が入力欄より2行多く表示されます。
- 1プロジェクトあたりの式履歴は最大4096件、保存データは最大16 MiBまでです。
- パネルで式を設定したオブジェクトは、同じプロジェクト内で使用してください。別プロジェクトへのコピーや、エイリアスファイルだけでの式の持ち運びには対応していません。
